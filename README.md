# Ejercicio-19---Modelo-Entidad-Relaci-n-de-un-Sistema-de-Crowdfunding
Este ejercicio consiste en diseñar un modelo Entidad-Relación (DER) para un sistema de financiamiento colectivo (crowdfunding)[cite: 9]. El modelo permite administrar usuarios, proyectos, recompensas asociadas e inversiones o aportes monetarios[cite: 9].
